Vice Cover Studio: Neon Reign — an offline GTA 6-style cover art maker. Turn your own photos into multi-panel Vice City posters with 6 layouts, 7 colour grades, 3 title styles, per-panel crop and position, callouts, a seal, role tags and a billing block, exported as PNG in 1080×1080, 1080×1350 and 1920×1080. No upload, no network: everything runs from local files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
